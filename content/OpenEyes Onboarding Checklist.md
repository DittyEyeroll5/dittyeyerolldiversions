## PHASE 7: SYSTEM TROUBLESHOOTING TRAINING

### Common Problems
- [ ] Can't log in → Reset password with IT admin
- [ ] System is slow → Close programs; try again
- [ ] Can't find patient → Search by different information
- [ ] Insurance code is wrong → Billing officer corrects
- [ ] Imaging won't upload → Compress file; try again
- [ ] PhilHealth claim rejected → Billing officer reviews and corrects
- [ ] Appointment won't schedule → Try different time
- [ ] Internet is down → Continue with paper backup
- [ ] System is down → Use paper forms; enter later

### When to Ask for Help
- [ ] Unsure about diagnosis code → Ask billing officer or doctor
- [ ] Unsure about procedure code → Ask billing officer or doctor
- [ ] Unsure about patient care → Ask doctor or supervisor
- [ ] Unsure about scheduling → Ask receptionist
- [ ] System problem → Ask IT admin
- [ ] Anything else → Ask supervisor
