## First Step DONE: Getting it to work
My first milestone was making OpenEyes work. While I was able to follow the [installation instructions](https://github.com/AppertaFoundation/openeyes/wiki/Installation-Instructions-v6.0), some of the installation instructions had some error codes and some parts were skipped. I was able to reconfigure and revise the installation instructions to work using the following settings
> OS: Ubuntu 24.04 LTS
> CPU (VM): 2 Core
> RAM: 4GB

I've included my [[OpenEyes Installation Instructions|revised installation instructions here]] if anyone is interested in replicating it. If you encounter any errors, please do send me an email.
